# Antigravity Prompt 02 — Product + UX Architecture

Now act as a Senior Product Designer and UX Architect.

Use the uploaded/product source-of-truth files:
- product requirements
- wireframe specification
- workflow state machine
- mock data
- design tokens
- site plan
- brand assets

## DESIGN THE PRODUCT AROUND THREE EXPERIENCES

### Buyer
Discover → Inspect → Select exact plot → Reserve → KYC → Mock Pay → Confirm → Track

### Developer
Onboard → Add project → Add inventory → Upload docs → Price → Submit → Manage leads/bookings

### Admin
Review → Verify → Approve/request changes/reject → Monitor inventory → Monitor payments/bookings → Audit

## INFORMATION ARCHITECTURE
Create a clear navigation map and record it in:
`docs/INFORMATION_ARCHITECTURE.md`

## UX OBJECTIVES
The interface must:
- feel trustworthy
- reduce cognitive load
- make exact inventory selection obvious
- show system status clearly
- prevent invalid actions
- expose price breakdown before payment
- keep primary actions obvious
- work well on mobile
- provide helpful empty/loading/error/success states

## KEY UX MOMENTS
Prioritize:
1. Homepage search
2. Search results
3. Project details
4. Exact plot site plan
5. Plot detail drawer
6. Hold countdown
7. Checkout
8. Mock payment
9. Booking confirmation
10. Booking timeline
11. Developer inventory
12. Admin verification

## REQUIRED CLIENT STORY
A first-time client must understand what the platform does within 30 seconds.

A first-time demo user must understand where to click without external explanation.

Document the UX story and interaction rules before implementing.
