# Antigravity Prompt 03 — Premium Design System

Build a reusable PlotNest design system based on `DESIGN_TOKENS.json`.

## VISUAL CHARACTER
Premium real estate + modern SaaS.
Calm, credible, simple, high information clarity.

## BUILD
- buttons
- inputs
- select/dropdowns
- cards
- badges
- tabs
- drawers
- modals
- tables
- breadcrumbs
- stepper
- timeline
- KPI widgets
- alerts
- toast
- skeleton
- empty states
- document cards
- navigation
- mobile bottom navigation

## STATUS LANGUAGE
Use both color and text/icon:
AVAILABLE
ON HOLD
BOOKED
BLOCKED
PAYMENT PENDING
VERIFIED
UNDER REVIEW
ACTION REQUIRED

Never rely on color alone.

## PROPERTY VISUAL LANGUAGE
Use strong property imagery, clean cards, site-plan visualization, location cues and verification badges.

## IMPORTANT
Create variants rather than duplicate components.

Create:
`docs/DESIGN_SYSTEM.md`

Include:
- spacing rules
- typography
- button hierarchy
- card hierarchy
- status rules
- responsive rules
- accessibility rules
- interaction states

Then implement the system.
