# Client Demo Narrative

## Opening
“PlotNest is a digital plot-booking platform designed around one simple idea: instead of only generating property enquiries, the customer can discover a project, choose an exact plot, temporarily reserve it, complete the booking flow and then track what happens next.”

## Part 1 — Buyer
Start with search.
Explain filters and trust indicators.

Open a project.
Explain that the project page combines information, inventory and documentation context.

Open the site plan.
Say:
“This is the inventory engine. Each plot is a real inventory object inside the system.”

Click an available plot.
Explain plot-level pricing and characteristics.

Reserve it.
Point out the timer.

Continue checkout.
Show the price breakdown and demo KYC.

Simulate payment success.
Show the confirmation and timeline.

## Part 2 — Developer
Switch role.

Say:
“On the supply side, the developer is not dependent on an external admin for everyday inventory management.”

Show:
Projects
Inventory
Leads
Bookings
Payments

Open the inventory.

## Part 3 — Admin
Switch role.

Say:
“The marketplace needs operational control, so projects do not automatically become public inventory without review.”

Open verification queue.
Show checklist.
Show approve/request changes/reject.

## Close
“This prototype validates the product workflow and user experience. The next production phase can replace the mock services with real authentication, database, payment gateway, notifications, CRM, document verification and registration-related integrations.”
